# Security Policy

## Supported versions

The active `main` branch and the latest published VeloFile release receive security fixes.

| Version | Supported |
| --- | --- |
| main | yes |
| latest signed release | yes |

## Release Integrity

VeloFile release builds are distributed as signed MSIX packages through the stable update channel documented in [docs/release/stable-update-channel.md](docs/release/stable-update-channel.md). The package signing identity is recorded in the release notes and package metadata.

## Reporting a vulnerability

Do not report vulnerabilities in public issues.

Use the repository's private GitHub Security Advisory reporting flow when it is available. If private advisories are unavailable, contact the maintainers through the repository owner profile before sharing exploit details. Include:

- affected version or commit
- reproduction steps
- impact
- any suggested mitigation

We will acknowledge receipt and follow up as soon as possible.
